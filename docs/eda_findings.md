# EDA まとめ — 購入フラグとの関係

最終更新: 2026-08-21 / 全体購入率 = 24.1%（購入179 / 全742）

分析スクリプト: `notebooks/eda_basic_corr.py` / `eda_financial_corr.py` / `eda_survey_corr.py` / `eda_text_corr.py`
指標: カテゴリ=Cramér's V, 数値=point-biserial r（＋Mann-Whitney/Spearman）, テキスト単語=log-odds

## 1. 企業基本情報

| 変数 | 効果量 | p | 判定 |
|---|---|---|---|
| 業界 | CramersV 0.348 | <0.001 | ◎ 最強 |
| 上場種別 | CramersV 0.176 | <0.001 | ○ |
| 特徴(BtoB/BtoC) | CramersV 0.149 | 0.003 | ○ |
| 従業員数 | r 0.081 | 0.027 | △ |
| 店舗数/工場数/事業所数 | r <0.06 | n.s. | × |

- **業界**が最強。高: 人材50%・IT47%・自動車45%・コンサル/金融33% / 低: 外食5%・小売7%・不動産/食品/運輸8%・建設9%。知的労働・IT寄りほど買い、店舗オペ型は買わない。
- **上場種別**: GR36% > PR28% ≫ ST12%（STが際立って低い）。
- **特徴**: 純BtoC企業は6.5%と極端に低い（BtoB27% / BtoB+BtoC24%）。
- **従業員数**: 購入群 median 1927 vs 非購入 1207。線形相関は弱いが分布差は明確（MW p=0.0001）→ log変換/カテゴリ化が有効そう。
- 拠点数系（事業所・工場・店舗）は単体ではほぼ効かない（業界交絡。店舗数は逆相関気味）。

## 2. 財務諸表

**「率」が生値を圧倒**（生科目の最大 r≈0.17 に対し、比率は 0.26〜0.32）。

| 変数 | r | 傾向 |
|---|---|---|
| 売上高経常利益率 | +0.317 | 収益性↑ほど買う |
| 売上高営業利益率 | +0.287 | 同上 |
| ROA | +0.262 | 同上 |
| 有利子負債比率 | −0.221 | 借金体質ほど買わない |
| 自己資本比率 | +0.159 | 健全なほど買う |
| 減価償却費率 | +0.161 | 設備投資活発なほど買う |
| 無形固定資産変動率 | −0.157 | ソフト投資大（支出=負値）ほど買う |
| 一人当たり営業利益 | +0.155 | 生産性↑ほど買う |

- 「儲かっていて財務健全で、投資に積極的な企業」がDX教育を買う、という一貫した構図。
- ROE・負債比率・流動資産比率は point-biserial ではほぼ0だが MW は有意 → 非線形（外れ値の影響）。木モデル向き。

## 3. アンケート

**多くの項目が逆相関**（スコアが高い企業ほど買わない）。単純合算スコアは打ち消し合って無効。

| 項目 | 意味 | r | 傾向 |
|---|---|---|---|
| アンケート7 | 既存ツール満足度(導入済のみ) | −0.258 | 不満なほど買う（1→46%, 5→13%）|
| アンケート10 | 外部パートナー連携 | −0.158 | 連携多いほど買わない |
| アンケート4 | DX変革への抵抗感 | −0.109 | 抵抗4-5で急落（非線形/閾値的）|
| アンケート2 | DX化満足度 | −0.092 | 満足なほど買わない |
| アンケート1 | DX戦略の明確さ | +0.073 | 唯一の順相関で有意 |
| その他(3,5,6,8,9,11) | — | ~0 | n.s. |

- **アンケート7が最強**。今のツールに不満な企業ほど新商材を買う（きれいな単調減少）。ただし356件は未導入で欠損。
- **合成「DX前向きスコア」は r=−0.046 で無効** → 符号を揃える/軸を分ける必要（重要な学び）。
- 非線形項目(4,10)はビン化 or 木モデルに委譲。

## 4. テキスト

- **文字数は無意味**（各テキストの `_len` は r≈0, n.s.）。効くのは長さでなく中身。企業名長のみ弱く有意だが業界交絡。
- **DXキーワード**: 「生成AI」出現企業の購入率 **54.3%**（全体の2倍超, 差+0.317）が突出。AI/IoT/クラウド/リスキリングも正。逆に「教育」「研修」「スキル」は無〜逆相関（一般語すぎ）。
- **組織図のDX部署**: あり29.2% vs なし17.7%（r=+0.134）。組織的コミットは効く。
- **購入を分ける単語（log-odds）**:
  - 購入↑: 圧倒的・力強く・一段と・強固・伸び・昇華（強い成長志向トーン）、ダッシュボード・テクノロジー・ナレッジ・キャリア（具体施策/人材語）。
  - 非購入↑: 抑える・小さく・極力・スモール・短時間・低い（コスト抑制トーン）、マニュアル・紙帳票・票・ポータル（旧来型業務）。
  - → **DX展望の「姿勢・語り口」（積極投資 vs コスト抑制）が購入を最も強く分ける**。TF-IDFでF1が0.66→0.72に跳ねた理由の正体。

## モデルへの示唆（特徴量追加フェーズの方針）

**追加すべき**
- 業界 target encoding（購入率エンコード, CV内fitでリーク防止）。上場種別・特徴も検討。
- 従業員数の log 変換。
- 「生成AI」出現フラグ（単独で強い）、DXキーワードを有効語（生成AI/AI/IoT/クラウド/リスキリング）に絞る。
- アンケート合成スコアの作り直し（符号を揃える。満足度系 2/7/8 と 戦略・整備系 1/5 を別軸に）。
- アンケート4・10 のビン化（抵抗4以上ダミー等）。
- アンケート7欠損フラグ×満足度低 の交互作用（最も熱いセグメント）。
- 姿勢語彙（積極 vs 抑制）の辞書スコアで TF-IDF を補完。

**削除/見直し候補**
- テキスト `_len`（文字数）特徴 — 効いていない。
- 単純な「DX前向きスコア合計/平均」 — 打ち消し合って無効。

**木モデルに委譲（変換不要）**
- ROE・負債比率・流動資産比率などの非線形指標。
